1、防止大型数组的意外拷贝

int a[9999] = {1,2,3,4,5.....};

int b[9999] = a;   // 拷贝整个数组

int a[9999] = {1,2,3,4,5.....};

int* b = a


b = a;   // 只需拷贝指针，b 和 a都指向&a[0]

-- 这个写法在C里实际不存在，编译会直接报错

我们只是假设，如果a是数组的话，那么这里会拷贝整个数组

-- C语言正确的写法
