Object的类型是【自然人】，而【自然人】根本没有姓名、年龄....这些属性

外面附加的这些属性是没有Type支持的，根本无法形成一个完整的Object

✔️ 要想让Object拥有这些属性，你必须在外层进行包装一个新Type

你可以给外层的类型取名叫【社会人】；但也可以不取，就保持匿名；但无论如何必须得有这层包装才算是一个完整Object

只有这样，向内查找时才能正确找到 @ 姓名、@年龄....这些属性

-- Object = Payload + Property ——是真正的0成本抽象，没有预留“槽位”的问题

例如你定义了一个MyInt，有个int payload，但没定义任何属性，这没问题✔️

例如各种基本类，它们已经是最底层的类了，没法包装其他东西了，只能别人包装基本类(以基本类为payload)

你所需的，将纤尘不染；不想要的，则绝不存在
