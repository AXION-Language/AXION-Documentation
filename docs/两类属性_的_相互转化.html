假设我们想给个 int 附加属性：

ver

update

random

compare

...

如果你希望这个属性跟着整个对象一起移动、赋值、拷贝....

那就放到【对象属性】里（定义在class T里）

你可以灵活地将它们分配给 句柄属性 or 对象属性，没有硬性标准，完全取决于个人需求

#compare(..){...}

#random(..){...}

#update(..){...}

#int ver : 0

int a : 0

两类属性的相互转化  与 注意事项

如果你希望这些属性仅依附于a ，右边对象随便怎么更换都不影响、仍然保持int类型

那就放到【句柄属性】里

#compare(..){...}

#random(..){...}

#update(..){...}

#int ver : 0

int payload


onNew(int v){this = v}

class MyInt

使用时

MyInt a ：new MyInt(5)


a@ver

a@update()

在class 内部，ver、update 是 int payload的 #句柄属性

若脱离了class，在外部访问时，则它们都是MyInt 的@对象属性
