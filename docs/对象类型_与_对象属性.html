-- 严格来说【方法体】不会随便复制，实际开发里，a和b是公用同一个【方法体/指令块】的

这和传统编程里的【引用对象，多个变量引用同一个对象】是技术层面完全不同的两个问题

——三言两语难以解释清楚， 之后我们在学到【解释型句柄】、【内存布局】、【函数】.....等各种知识后再系统性的解释


但是本例中，定义函数时刻意用【实例型句柄 #fn update() : {...}】来定义，这就表示它确实是一个可独立拷贝的数据块，所以拷贝后就会得到2个方法体

语义逻辑上这是完全正确的，单纯的数据拷贝操作系统并不会报错✔️

只是为了让操作系统能正常执行这段指令，得给这个指令块单独分配一个4KB内存页并设置RX权限（成本很高）


总之，AXION的设计哲学是

优先确保【语义 与 认知 的统一】这种原则性问题，确保你有一个稳定、全知的世界观，确保你能完整掌控任何一个原子级逻辑

至于好不好、成本高不高，那是另一回事（随便一个设置就解决了）

而不是像传统编程那样，强制屏蔽底层 + 不给个合理解释 + 各种各样的特殊规则，根本无法用同一世界观去理解
