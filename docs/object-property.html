现实中的人、狗、车.....是对象

编程中的数组、结构体、链表....是对象

在传统编程遭受不公平待遇的整型、字符、字符串、布尔值、甚至是1bit的01电位...在AXION里也是对象

更抽象的概念如数学符号、心情与想法、时间与空间、场景与事件....也都是平等的对象

新世界的大门已打开，你需要的只是想象力

1、任何对象都能有属性，包括int、char、string...这些基本类型

2、能在不破坏源对象的情况下，额外地用属性存储很多辅助性数据 —— 无论属性多么复杂，都不影响源对象的使用

3、没有变量命名负担，不用绞尽脑汁去处理get value、__value、__body...之类的冲突

4、逻辑干净且优雅，充分发挥想象力，绝大多数功能都可以在AXION里用【属性模型】轻松解决

      无论是认知成本，还是未来拓展新功能的成本，都几乎为0；

而这一切，在传统编程里，则需要通过各种特殊语法、特殊关键字、类与继承、装饰器和代理、设计模式、臃肿框架.......才能拐弯抹角地"模拟"出来
