为什么有这种硬性规定？

换句话说，如果你连一个Object是什么Type都不知道，则意味着它在你眼里只是一个类似于“东西、事物、物体...”这样的客观存在

想象一下，在某个你不知道的宇宙角落里有一块石头，它客观上有质量、有体积、有空间、有上下文.....但这一切都只是寄生于客观实体本身的客观事实，而不是属性！


而当你看见它的那一刻，你大脑里会根据几十年的生活习惯，自动为其包装各种Type：

Type 石头 {成分:碳酸钙、二氧化硅.....硬度....}

Type 食物？{热量、口味...}  —— Throw TypeException，跳过，接着继续包装.....

Type 物理实体 {体积、质量、颜色....}

.....

这就是人类最真实的认知过程


——我们只是把 {成分、颜色、热量、口味、质量...}这些乱七八糟认知角度分分类，取个好记的Type名而已（Type 石头、Type 食物、Type 物理实体.....）

关键在于这句话的理解 

在AXION定义【Object】之前，上面这句话是不成立的

很简单的道理，宇宙中有一块石头，它的质量、体积、成分组成....等各种特性都客观存在，跟我认不认知有啥关系？

Type决定了一个Object的结构与边界

但现在AXION定义了Object是【主观认知层面的关系模型】，那这句话就成立

这句话的完整表述是：Type决定了一个Object的认知结构 与 认知边界 —— 但由于Object本身就是认知层的概念，所以省略了“认知”两个字

所谓Type其实只是一种人类自身的【认知模板】，而不是说一个Object必须要依附另一个Object才能存在

当你第一次看到“Object 必须与Type 强绑定”的时候，之所以会无法接受
