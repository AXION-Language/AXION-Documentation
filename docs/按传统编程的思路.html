区分 基本类型/值类型 & 对象类型/引用类型

int a : 10

Integer a ：new Integer(10)

用 int 表示值类型：

不可变，无属性，可能存在于指令、也可能存在于数据段，取决于编译器自己的判断


用 Integer 表示对象类型：

可变、有属性、靠指针间接寻址、是引用类型..... 

int a :: 10

int b :: a


b = b + 5

接着回到问题

int是值类型，a也是值类型，所以编译通过

✔️ 编译报错：int是值类型，值类型不可赋值 —— 报错正是我们的目的

“如果按这个逻辑，那对象与值的哲学意义是.......？”

“对于一个int a = 2，为什么我不能认为它是对象呢？”

“明明说a是个变量，又为什么说不可改？”

“况且a明明占内存，有内存地址，为什么不让改？但明面上说不可改，又为什么暗地里偷偷原地修改？”

....

或是反过来规定int是对象类型，Primary是基本类型/值类型

int是值类型

Integet是对象类型

PrimaryInt a ：10

int a : new int(10)


int是对象类型类型

PrimaryInt是值类型

如果你的思维还是传统编程的形状，就会得到类似下面的方案

不过传统编程没有【句柄】和【解释型句柄】之类的概念，这里只是模拟

value 标记

int a :: 10

value int b :: a


b = b + 5

用value表示值类型，编译通过

正如static、const、var......之类的关键字

✔️编译报错，value类型不可被赋值
