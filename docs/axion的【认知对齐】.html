想要遍历，就用【字符数组】

char[11] s :“hello world”

for (let i = 0; i < str.length; i++) {

    print s[i]

}

-- 加上空格共11个字符 (length = 11 )，签名里可以不写11，编译器自己会数

-- h e l l o w o r l d

数组确保了每个字符一定是等长的，例如固定占1字节，或2字节 (1个码元可以包含多字节)

那么编译器就可以提供完整的支持：自动计算length、允许遍历

想要变长数组、维护length防越界、维护capacity动态扩容...就自己封装个【class String】
