更关键的是，所有传统编程都要求你必须建立一个对象，你无法对普通int直接进行这样的操作！

例如 js的getter已经算是最简单的了，但却无法添加给普通数字，你必须定义成对象，然后才能在对象内添加getter，而且还必须占用一个value的命名

let obj = {

    _value: 10,

    get value() {...}

};

....各种各样的附加逻辑，无形中给开发者增添了不少编程负担
