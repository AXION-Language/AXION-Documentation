C语言：自动加\0

AXION对字符串的处理，和C等语言有着根本上的不同

例如同样对于 "aaaa"

char str[] = "aaaa"

const char* str = "aaaa"

char str[4] = "aaaa";   // ❌ 不行！不够放'\0'，编译警告

char str[5] = "aaaa";   // ✔️ 对，留一个给'\0'

总之，无论你用任何姿势写，"aaaa"都会被处理成

a

a

a

a

\0

自动加个 \0 作为结束符
