Q：为什么需要指针？

A：为了直接操作源对象

指针并非抽象概念，它本身也是客观存在的内存数据

void fn(int x) {

    x = x + 1; 

}


int a = 1;

fn(a);         

printf("%d",a);


void fn(int* x) {  

      *x = *x + 1;   

}


int a = 1;

fn(&a);         

printf("%d",a);

如果没有指针，则无法修改源对象

通过指针，可直接修改源对象

-- 传入a的值(1) ，此时x=1，fn修改x不影响源对象a

-- 操作的是x，不是a

-- a仍然是1

-- 通过*解引用，直接操作源对象

-- 声明x是个int的指针对象

-- 通过&取地址，此时x=a的地址(0x1000)，*x解引用后指向a，所以fn可直接操作a的值

-- a=2

int a=1;

int* b=&a;

printf("%p",b)

类比于现实： 指针 好比于  身份证/手机号/货架号

可通过 身份证/手机号 找到目标人物;

而若是货架号这种有序的，自然也可以进行数学运算

int a=1;

int b=2;

int* c=&a;


printf("&a = %p\n", &a);

printf("&b = %p\n", &b);


printf("c = %p\n", c);

printf("c-1 = %p\n", c-1);

printf("c-4 = %p\n", c-4);


printf("%d\n", *(c-1));

printf("%d\n", *(c-4));

指针可直接参与运算，但需乘上size of T的倍数，例如int是4字节，则指针运算里的1相当于4
