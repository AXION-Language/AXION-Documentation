包装——人类最基本的认知模式

前文虽已铺垫了不少“包装”相关知识，而本模块有两方面职责：

一、更系统化地解释“包装是什么”—— 这不是单纯的总结，而是进一步抽象与拓展

二、基于包装而进行的：运算、比较、层级....等生态 —— 之前空下的《对象属性的用法》将在此做详细解释

——这是人类最基本的认知模式，也是“包装”的这个概念的适用范围

-- 回顾我们学过的知识，其实到处都有【包装】的身影

客观上：0x1000只是一个【地址】，一串类似于手机号、身份证的纯数字

主观上：我可以通过这串数字，索引到目标数据。所以将其取名为【指针】，意味着它有“解引用”的能力

客观上：Payload是T1类型（假设T1的定义是纯物体，只是客观存在着，却没有属性）

主观上：我们需要研究payload的物种分类、染色体数量、骨骼数、体温范围.....，所以将这些属性打包起来，定义为 T2 类型

-- 还记得AXION对属性的定义吗？不是客观事实，而是主观上你选择去维护的才叫属性

- 从类型层面看：T2 是 T1的【包装类】

- 从对象层面看：T2 Object 是对T1 Payload的包装（或者说T2 Object里包装了一个T1 Object）

Object可以作为Payload继续拥有属性，并打包形成更高层级的Object，这就是【包装链】：

【AXION里的包装】是一套单独的、系统的、有着中流砥柱价值的理论体系，其重要性之高体现在：
