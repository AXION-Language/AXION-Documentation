所以，传统编程理论说：要先把int类型转成对象类型，再辅以运算符重载 、代理 等手段

class AngleInt {

public:

    int value = 1

    int angle = 90

    MyInt(int a) : angle(a) {...}


    // 运算符重载

    int operator+(const AngleInt& other) {

        return value + other.value;

    }


    int operator+(int other) {

        return value + other

    }

};


运算符重载、代理...没本质区别，这里以 C++运算符重载为例
