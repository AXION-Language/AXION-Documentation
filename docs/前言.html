之前，虽然我们已经给出了一系列模型，表面上看是很好，实则底层缺乏稳定的理论支撑

开头我们定义的那些Object、Property 都是按传统理论、传统认知，所给出的最粗浅的解释，但一旦遇到复杂逻辑就原形毕露了

警惕 自然语言 与 惯性思维 的协同犯案！

本模块的职责

严格定义对象、属性、句柄

例如我们当时的定义

-- 至今以来所受的教育，令我对此坚信不疑，但这就是大坑

而本模块，我们就来“夯实”这最底层的理论——严格定义：对象、属性、句柄

自然语言里到处都是“陷阱”

连自己的大脑都变得不可相信

—— 本模块的学习中，务必要保持良好精神状态  与 清醒的头脑

一切都从这个简单问题开始——

构想一个场景：

某个人/这个人/小明

地球

问：【某个人/这个人/小明的属性】 是什么？可能的回答是——

姓名

性别

年龄

地理位置

在天空下

在树林边

固有属性：始终伴随这个人，不随环境而变化

环境属性 /上下文属性

结论：

属性架构 = 固有属性 + 上下文属性

-- 这是AXION早期的方案 —— 以防万一强调下，这不是好不好的问题，而是彻底错误的

按这个思路做下去，后面逻辑乱的一塌糊涂，AXION早死半路上了....
