用  ::   或  => 当做【解释符】， 或自己随便编一个

一开始设计时，是用=>当解释符的，因为当时想着是和 指针-> 对应起来

AXION不约束表示层语法，自己怎么喜欢怎么来，只要逻辑正确就行

int a ：10

int b -> a

int c => a

-- 指针有#addr的内存成本 + 运行时动态转发的指令成本

-- 解释是编译期的静态转发，运行时0成本

但后来还是改成了  :: ，因为是想着和 实例型句柄：对应起来

int a ：10

int b :: 10

-- a是个初值为10的int变量，因此这个int对象需长期占用内存，长期维护

-- a就是10这个值！不占用固定内存，只在诸如 b+5 这种过程指令里被当做操作数

总之，AXION目前默认使用 双冒号 :: 当做【解释符】

 :: 这个符号在AHK里也是有类似“解释”的含义

F5 :: Reload

F4 :: Suspend Toggle

LButton ::

    send,{LButton}

    Sleep, 300

    send,{WheelUp}

Return

-- 我个人经常用AHK，所以 :: 在我心中的权重更高一些
